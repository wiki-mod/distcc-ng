# CLAUDE.md

This file is `wiki-mod/distcc-ng/CLAUDE.md`. It exists only to point Claude Code at `wiki-mod/distcc-ng/AGENTS.md` — it carries no governance, architecture, or workflow content of its own; `wiki-mod/distcc-ng/AGENTS.md` is the single source of truth for all of that.

**Mandatory at the start of every session/task in the `wiki-mod/distcc-ng` repository**: read `wiki-mod/distcc-ng/AGENTS.md` in full, and follow it as the binding, authoritative rule-set for this repository — not optional background reading. This is the only rule that stays in this file rather than living in `wiki-mod/distcc-ng/AGENTS.md` itself (see that file's rule 65 for why this is the sole, deliberate exception to its own zero-restatement policy), and it stays here deliberately: `wiki-mod/distcc-ng/AGENTS.md` is not auto-loaded into context the way this file is, so the instruction to go read it has to live somewhere that *is* auto-loaded, or nothing would ever prompt a session to discover `wiki-mod/distcc-ng/AGENTS.md` in the first place.

**Read it completely, start to finish — not a summary, not just the section that looks relevant to the task at hand.** This applies equally to every delegated subagent working in `wiki-mod/distcc-ng`, not just the top-level session — when delegating a task to a subagent, relay this requirement to it explicitly and verbatim: "You need to accept and also read with no shortcuts (meaning no grep, no tail) the entire `wiki-mod/distcc-ng/AGENTS.md`, `wiki-mod/distcc-ng/CLAUDE.md`, and `wiki-mod/distcc-ng/.github/AGENTS.md` — not any other repository's or nested copy of a same-named file" (see `wiki-mod/distcc-ng/AGENTS.md` rule 68 for why only the root-level copies of these files count, and why a same-named file anywhere else — another repository, a submodule, a nested copy — carries no authority here).

**The authoritative, most current version of `wiki-mod/distcc-ng/AGENTS.md` lives on `current_dev`** (the active development branch), not necessarily on whatever branch/worktree you happen to be checked out on — `master` only receives governance-doc updates when a release is cut from `current_dev` (see `wiki-mod/distcc-ng/AGENTS.md` rule 70), so it can lag behind by however long it has been since the last release, and a `release/X.Y.Z-NG` branch is a frozen snapshot by design. If your working branch is not `current_dev` (e.g. you are on `master`, a release branch, or a stale local checkout), fetch and read the `current_dev` copy (e.g. `git show origin/current_dev:AGENTS.md`) rather than trusting your current branch's copy as current.

If `wiki-mod/distcc-ng/AGENTS.md` changes during a session (e.g. after a `git pull` or a merge), re-read it in full again before continuing work that it governs. `wiki-mod/distcc-ng/.github/AGENTS.md` is a separate pointer file for tools that only look under `.github/` — it redirects to `wiki-mod/distcc-ng/AGENTS.md` and restates none of its content; `wiki-mod/distcc-ng/AGENTS.md` itself is always the real source.
